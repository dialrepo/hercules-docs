    # Configuración del correo. Se hace durante el despliegue. En la implantación del piloto de Murcia tiene los siguientes valores:     - name: SPRING_MAIL_HOST       value: "smpt.um.es"     - name: SPRING_MAIL_PORT       value: "465"     - name: SPRING_MAIL_USERNAME       value: noreply@um.es     - name: SPRING_MAIL_PASSWORD       value: ""     - name: SGI_DISABLE-EMAIL-SEND       value: "false"     - name: SGI_FAKE-EMAIL-RECIPIENTS       value: fakeSGI@um.es En este caso, todos los correos se generan desde la cuenta noreply@um.es y llegan al correo fakeSGI. # CSP ## Tabla Configuracion
    Nombre campo Valor
    formato_partida_presupuestaria 
    ^[A-Z0-9]{2}\\.[A-Z0-9]{4}\\.[A-Z0-9]{4}(\\.[A-Z0-9]{5,})$
