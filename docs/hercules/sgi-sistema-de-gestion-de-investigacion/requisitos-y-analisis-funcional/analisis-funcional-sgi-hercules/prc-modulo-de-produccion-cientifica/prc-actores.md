# PRC - Actores

Los diferentes roles de usuario de carácter general que actuarán con el sistema son los que se enumeran a continuación.

|  |  |  |
| --- | --- | --- |
| **Nombre** | **Descripción** | **Notas / Características** |
| **ACT-PRC-001-Investigador** | Personal de investigación. Podrá tener diferentes roles de participación:   * como investigador: accede únicamente a los informes de baremación * como investigador principal de un grupo de investigación: accede a los informes de baremación y a la validación de producción científica * como persona autorizada a la labor de validar/rechazar los items de  producción científica: accede a los informes de baremación y a la validación de producción científica | * Personal investigador y docente perteneciente a la Universidad * Alumnos/as que realicen másteres o trabajos de tesis o grado |
| **ACT-PRC-003-Gestor** | Tendrá acceso a todos los items de producción científica y podrá Validar/Rechazar cualquier item.  Acceso a los informes de baremación de todos los grupos e investigadores  Acceso a la configuración de convocatorias y de la tabla de experimentalidad |  |
| **ACT-PRC-004-Visor** | Acceso en modo consulta a todas las opciones de menú: Validación de items, Informes, Convocatorias y Configuración |  |
