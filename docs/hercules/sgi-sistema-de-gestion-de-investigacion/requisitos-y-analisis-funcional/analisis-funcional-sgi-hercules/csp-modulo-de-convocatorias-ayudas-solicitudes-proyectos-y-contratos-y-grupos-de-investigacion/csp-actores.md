# CSP - Actores

|  |  |  |
| --- | --- | --- |
| Nombre | **Descripción** | **Observaciones** |
| ACT-CSP-001-Investigador | Personal investigador. Es un actor prioritario en este módulo. Deberá tener acceso para consultar las convocatorias disponibles, deberá poder registrar las solicitudes (aquellas que se habiliten a través del SGI), deberá poder consultar el estado de los proyectos en los que participa y deberá poder consultar los grupos de investigación a los que pertenece.  Un investigador podrá tener diferentes roles de participación:   * miembro del equipo de un proyecto de investigación * investigador principal de un proyecto de investigación * responsable económico de un proyecto de investigación * miembro de un grupo de investigación o un grupo de transferencia de conocimiento * investigador principal de un proyecto de investigación * responsable económico de un grupo de investigación o de transferencia del conocimiento * persona autorizada de un grupo de investigación * coordinador o persona autorizada de un grupo de transferencia del conocimiento | Puede darse el caso que un investigador pudiera actuar como gestor, administrador o visor de una oficina o unidad de gestión. |
| ACT-CSP-002-InvestigadorExterno | Personal investigador, sin vinculación contractual con la Universidad. Será candidato a acceder a la información de los proyectos en los colabora, es decir, de aquellos proyectos en los que figura como miembro del equipo. Para ello debe de disponer del usuario convenientemente configurado en el sistema de autenticación corporativo. |  |
| ACT-CSP-003-Gestor | Personal de gestión. Un gestor pertenecerá una unidad, oficina o servicio. Se entiende por unidad u oficina, por ejemplo, UGI, OTRI, OPE o SAI.  Es el actor principal en este módulo, es quien inicia el flujo al registrar las convocatorias, revisará las solicitudes presentadas por el personal investigador (ACT- CSP-001-Investigador), realizará el seguimiento de proyectos, con especial prioridad a la recopilación de la información necesaria para la justificación económica. En el caso de las acciones de RRHH deberá tener disponible la información asociada a la duración de los contratos.    El personal de gestión podrá tener permisos (en el SGI) sobre más de una unidad de gestión. Sobre cada una de las unidades podrán actuar como gestores (ACT-CSP-003-Gestor), administradores de datos (ACT-CSP-004-Administrador) o visores de la información (ACT-CSP-005-Visor). Las convocatorias quedarán asociadas a una unidad de gestión en el momento de su creación. El usuario accederá a la información de la convocatoria (y sus solicitudes y proyectos derivados) en función del rol con el que esté adscrito a la unidad de gestión creadora de la convocatoria. Si el gestor no está asociado a una unidad de gestión concreta no podrá visualizar ninguna convocatoria, solicitud, proyecto de esa unidad. |  |
| ACT-CSP-004-Administrador | Personal de gestión que puede realizar la gestión de datos maestros asociados a un determinado módulo del SGI.  Tendrá permisos para poder realizar la gestión (creación de nuevos registros, modificación o eliminación) de los datos de categorización utilizados en la gestión de las entidades principales de este módulo (convocatorias, solicitudes y proyectos). Ejemplo: tipos de proyectos.  Como en el caso anterior el personal de gestión podrá tener permisos (en el SGI) sobre más de una unidad de gestión. Sobre cada una de las unidades podrán actuar como gestores (ACT-CSP-003-Gestor), administradores de datos (ACT-CSP-004-Administrador) o visores de la información (ACT-CSP-005-Visor). Las convocatorias quedarán asociadas a una unidad de gestión en el momento de su creación. El usuario accederá a la información de la convocatoria (y sus solicitudes y proyectos derivados) en función del rol con el que esté adscrito a la unidad de gestión creadora de la convocatoria. Si el gestor no está asociado a una unidad de gestión concreta no podrá visualizar ninguna convocatoria, solicitud, proyecto de esa unidad. |  |
| ACT-CSP-005-Visor | Personal de gestión que solamente puede acceder en modo lectura a los datos de las convocatorias, solicitudes y proyectos.  Como en el caso anterior el personal de gestión podrá tener permisos (en el SGI) sobre más de una unidad de gestión. Sobre cada una de las unidades podrán actuar como gestores (ACT-CSP-003-Gestor), administradores de datos (ACT-CSP-004-Administrador) o visores de la información (ACT-CSP-005-Visor). Las convocatorias quedarán asociadas a una unidad de gestión en el momento de su creación. El usuario accederá a la información de la convocatoria (y sus solicitudes y proyectos derivados) en función del rol con el que esté adscrito a la unidad de gestión creadora de la convocatoria. Si el gestor no está asociado a una unidad de gestión concreta no podrá visualizar ninguna convocatoria, solicitud, proyecto de esa unidad. |  |
