# SGI - Interface integración

El SGI dispone de tres mecanismos de integración para aquellas universidades que lo quieran implantar:

* Una serie de métodos expuestos a través de un API REST denominado ESB que se describen aquí: [SGI - ESB](/hercules/sgi-sistema-de-gestion-de-investigacion/diseno/componentes/sgi-esb)
* Unas consultas que se pueden utilizar para llevar a cabo acciones en los sistemas de la Universidad que lo implante y que se describen aquí: [SGI - Consultas integración](/hercules/sgi-sistema-de-gestion-de-investigacion/diseno/componentes/sgi-interface-integracion/sgi-consultas-integracion)
* Unas vistas para poder consultar cierta información del SGI y que se describen aquí: [SGI - Vistas](/hercules/sgi-sistema-de-gestion-de-investigacion/diseno/componentes/sgi-interface-integracion/sgi-vistas)
