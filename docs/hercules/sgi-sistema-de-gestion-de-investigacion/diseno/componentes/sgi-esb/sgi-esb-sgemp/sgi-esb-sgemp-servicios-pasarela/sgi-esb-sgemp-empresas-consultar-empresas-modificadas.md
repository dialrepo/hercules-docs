# SGI - ESB - SGEMP - Empresas - Consultar empresas modificadas

|  |  |
| --- | --- |
| Método | GET |
| URL | /empresas/modificadas-ids |
| Parámetros | q+s  La query estará formada por:   * fechaModificacion |
| Respuesta | Lista[String] |
| Descripción | Listado de los identificadores de empresas que han sufrido cambios en los datos de identificativos de la empresa o en sus datos de contacto. |
