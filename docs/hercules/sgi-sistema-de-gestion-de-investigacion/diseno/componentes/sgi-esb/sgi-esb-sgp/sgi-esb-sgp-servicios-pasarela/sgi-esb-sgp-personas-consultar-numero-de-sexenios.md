# SGI - ESB - SGP - Personas - Consultar número de sexenios

|  |  |
| --- | --- |
| Método | GET |
| URL | /sexenios/persona/{id} |
| Parámetros | fecha |
| Respuesta | [Sexenio](/hercules/sgi-sistema-de-gestion-de-investigacion/diseno/componentes/sgi-esb/sgi-esb-sgp#SGIESBSGP-Sexenio) |
| Descripción | Devuelve el número de sexenios de la persona. Si se le pasa el parámetro de la fecha devuelve el número de sexenios en esa fecha, sino se devuelve el número de sexenios a la fecha actual.  Ejemplo:   * fecha="2021-08-18T22:00:00Z" |
