# SGI - ESB - SGP - Personas - Formación - Consultar detalle

|  |  |
| --- | --- |
| Método | GET |
| URL | /formacion/{id} |
| Parámetros | * tipoFormacion: tipo de formación que se quiere recuperar, usando los códigos de CVN |
| Respuesta | Lista[Formación (del tipo solicitado)]  Ver entidades en <https://confluence.um.es/confluence/pages/viewpage.action?pageId=397534658> |
| Descripción | Detalle sobre los datos de la Formación Recibida, dependiendo del ID de la persona y el tipo de formación.  Ejemplo:   * /formacion/22468643?tipoFormacion="020.050.000.000" |
